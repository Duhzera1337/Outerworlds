# FAQ ❓

> **Q:** Does Outerworlds support Multiplayer?:
> 
> **A:** Yes, it does but with a few notes. For it to work, some mods have to be added to the server and all the players need to have the same mods and their respective versions.

> **Q:** Will the modpack get updated to later Minecraft Updates?:
> 
> **A:** Yes, it is planned to but it requires patience. Some mods that plays big parts of Outerworlds are not available for 26.0 or above, so I prefer to wait and ship a full package instead of uploading a half-baked one.

> **Q:** Is there a way to report bugs or ask for help?:
> 
> **A:** Yes, you can open an issue on GitHub or a ticket in Outerworld's Discord Server

Also, **DO NOT UPDATE SODIUM!** It might cause **compatibility issues** (aka: launch erorrs, crashes/low framerate and visual glitches)


# Known Issues ❗

> **Issue:** JVM/Java Arguments warning when launching (Patched in v1.3.0):
> 
> **Solution:** In your launcher, find the profile settings, search for JVM/Java Arguments and paste this:
> 
>  "--add-modules jdk.incubator.vector"

> **Issue:** Strong stutters when using the Spyglass:
> 
> **Solution:** This is an issue caused by Voxy and it's unlikely to be fixed by now. In this case, don't move the camera too much when using the Spyglass
